ADAS Dataset Generator

주행 영상에서 Occlusion 차량 이미지를 자동 추출하여
ADAS 학습용 데이터셋을 생성하는 AI 기반 서비스

📌 프로젝트 개요

ADAS(첨단 운전자 보조 시스템)는 차량을 정확히 인식하는 것이 중요하지만, 실제 도로 환경에서는 차량이 구조물·가드레일·수풀 등에 의해 부분적으로 가려지는 Occlusion 상황이 자주 발생합니다. 발표자료에서도 이러한 Occlusion 상황이 ADAS 성능 저하의 원인이 될 수 있음을 문제로 정의하였음.

본 프로젝트는 주행 영상 속에서 가려진 차량 이미지를 AI가 자동으로 판단하고 추출하여, ADAS 학습용 데이터셋을 자동 생성하는 서비스를 목표로 진행되었습니다.

❗ 문제 정의

기존에는 Occlusion 차량 데이터를 직접 수집하고 라벨링해야 했기 때문에:

데이터 수집 비용 증가
반복적인 수작업 발생
실제 도로 환경 데이터 부족

문제가 존재했습니다.

또한 관련 논문 조사 과정에서 실제 교통 환경에서 Occlusion 데이터셋이 부족하다는 점을 확인하였고, 이를 해결할 수 있는 방향으로 프로젝트를 기획하였습니다.
