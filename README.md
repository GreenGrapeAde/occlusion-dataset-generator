# ADAS Dataset Generator

> 주행 영상 속 Occlusion 차량 이미지를 자동 추출하여  
> ADAS 학습용 데이터셋을 생성하는 프로젝트

---

## 📌 Overview

- 주행 영상 기반 Occlusion 차량 이미지 자동 추출
- ADAS 학습용 데이터셋 생성 자동화
- 웹 기반 영상 업로드 및 ZIP 다운로드 기능 제공

---

## ❗ Problem

실제 도로 환경에서는 차량이 구조물·가드레일 등에 의해 가려지는 Occlusion 상황이 자주 발생하며, 관련 데이터셋 부족 문제가 존재함.

### Reference
- [Paper Link](https://www.nature.com/articles/s41598-024-70695-x)

## 👤 Role

- 기업 요구사항 분석

---

## 🔄 Workflow

1. 주행 영상 업로드
2. AI 기반 차량 탐지
3. Occlusion 이미지 자동 추출
4. 데이터셋 생성
5. ZIP 파일 다운로드
